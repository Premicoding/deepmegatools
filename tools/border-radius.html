What Is CSS Border Radius?

The CSS border-radius property creates rounded corners on HTML elements. It can be applied to buttons, cards, images, containers, input fields, profile pictures, and many other web components.

.box { border-radius: 20px; }

Instead of calculating different corner values manually, use a Border Radius Generator to create the required CSS visually.

Simple Border Radius Mode

Simple mode lets you control each of the four corners independently. Adjust the top-left, top-right, bottom-right, and bottom-left radius values using sliders — ideal for asymmetric designs.

.box { border-radius: 20px 40px 60px 10px; }

The four values represent the top-left, top-right, bottom-right, and bottom-left corners respectively.

Complex Border Radius Mode

Complex mode gives you separate horizontal and vertical control for each corner, enabling advanced CSS shapes and custom designs.

.box { border-radius: 30% 60% 40% 20% / 50% 30% 70% 40%; }

The Border Radius Generator creates this type of CSS automatically.

Percentage vs Pixel Border Radius

Using Pixels (px)

Pixel values provide a fixed radius. Example: border-radius: 25px;

Using Percentages (%)

Percentage values create flexible and responsive shapes. Example: border-radius: 50%;
