Introduction to CSS Animations

CSS animations let you animate transitions from one CSS style configuration to another. They consist of two components: a style describing the animation, and a set of keyframes that indicate the start, end, and intermediate states of the animation. 

/* Basic animation syntax */
@keyframes example {
  from { background-color: red; }
  to   { background-color: yellow; }
}

.element {
  animation-name: example;
  animation-duration: 4s;
}

Animation Properties

CSS animations are controlled with the following properties:

  • @keyframes: Defines the animation name along with CSS property values at each step.
  • animation-name: Specifies the name of the @keyframes rule.
  • animation-duration: Defines how long the animation takes to complete one cycle.
  • animation-timing-function: Specifies the speed curve of the animation.
  • animation-delay: Specifies a delay before the animation starts.
  • animation-iteration-count: Defines how many times the animation runs.
  • animation-direction: Specifies whether the animation plays in reverse on alternate cycles.
  • animation-fill-mode: Specifies the styles applied to the element before and after the animation runs.
  • animation-play-state: Specifies whether the animation is running or paused.

Animation Shorthand & Default Values

The animation shorthand combines all sub-properties into one declaration. Its default value is: 

.element {
  animation: name duration timing-function delay iteration-count direction fill-mode play-state;
}

/* Default value */
animation: none 0 ease 0 1 normal none running;

This expands to the following individual defaults:

  • animation-name: none — no animation is applied
  • animation-duration: 0s — animation plays instantly
  • animation-timing-function: ease — slow start, fast middle, slow end
  • animation-delay: 0s — animation starts immediately
  • animation-iteration-count: 1 — animation plays once
  • animation-direction: normal — plays forwards
  • animation-fill-mode: none — no styles applied before or after execution
  • animation-play-state: running — animation is playing

What are CSS @keyframes?

@keyframes let you define styles at various points during the animation sequence. You specify what styles the element has at certain times, and the browser fills in the transitions between those keyframes. 

@keyframes animation-name {
  from { /* starting styles */ }
  to   { /* ending styles   */ }
}

/* Equivalent syntax using percentages */
@keyframes animation-name {
  0%   { /* styles at 0%   */ }
  100% { /* styles at 100% */ }
}

/* Multiple intermediate steps */
@keyframes animation-name {
  0%   { /* styles at 0%   */ }
  50%  { /* styles at 50%  */ }
  100% { /* styles at 100% */ }
}

What are Timing Functions?

Timing functions (also called easing functions) specify the rate of change of an animation over time. They make animations feel more natural by controlling acceleration and deceleration. Instead of moving at constant speed, objects in the real world speed up, slow down, and bounce — timing functions recreate these natural movements.

Timing Function Details

  • ease — Slow start, fast middle, slow end. (default)
  • ease-in — Slow start, fast end (accelerates).
  • ease-out — Fast start, slow end (decelerates).
  • ease-in-out — Slow start and end, faster middle (symmetrical version of ease).
  • linear — Constant speed throughout, no acceleration or deceleration.
  • steps(n) — Divides the animation into n discrete steps. steps(5) creates 5 jumps.
  • cubic-bezier(x1, y1, x2, y2) — A custom timing function defined by a Bezier curve. This lets you fine-tune exactly where the animation speeds up or slows down.
    ⚠️ Important: x1 and x2 must be between 0 and 1, but y1 and y2 can go outside this range — this is what allows bounce and overshoot effects.

CSS Animation Direction

This property sets the direction in which the animation plays. Values:

  • normal (default) — Plays forwards, 0% → 100%.
  • reverse — Plays backwards, 100% → 0%.
  • alternate — Plays forward first, then backward, then forward again — repeating continuously.
  • alternate-reverse — Plays backward first, then forward, then backward again — repeating continuously.

CSS Animation Fill Mode

The animation-fill-mode property controls what styles are applied to the element before and after the animation runs.

  • none (default) — No animation styles are retained. The element uses its normal styles before, during (until the animation actually starts), and after.
  • forwards — After the animation ends, the element keeps the styles from the last keyframe (100%).
  • backwards — During the delay period (before the animation starts), the element uses the styles from the first keyframe (0%). After the animation ends, it reverts to its normal styles.
  • both — Combines forwards and backwards: applies the first keyframe's styles during the delay, and retains the last keyframe's styles after the animation ends.

Bonus: Accessibility & Performance Tips

Respect user preferences (prefers-reduced-motion)

Some users experience motion sickness from animations. Always honor the prefers-reduced-motion media query: 

@media (prefers-reduced-motion: reduce) {
  .element {
    animation: none;
  }
}

Optimize for performance

For smooth 60 fps animations, prefer animating transform and opacity over layout-triggering properties like width, height, top, or left. Use will-change sparingly to hint the browser to optimize ahead of time: 

.element {
  will-change: transform;
}

Run multiple animations on one element

Separate multiple animations with commas:

.element {
  animation: slideIn 1s ease, fadeIn 2s ease;
}

Conclusion

CSS Animation is a powerful way to make websites more attractive, interactive, and modern. It allows developers to add impressive animations to text, buttons, images, and other HTML elements without relying on JavaScript.

By using CSS properties such as @keyframes, animation-duration, animation-delay, animation-timing-function, and animation-iteration-count, you can create smooth animations, loading effects, button animations, and engaging website interfaces.

Whether you want to add a simple hover effect to a button or create advanced animations for an entire website, CSS Animation can help improve your web design and user experience. However, animations should be used carefully to maintain website performance and avoid unnecessary visual distractions.

You should also consider users who prefer reduced motion. The CSS prefers-reduced-motion media query helps developers provide a more comfortable browsing experience for these users.
