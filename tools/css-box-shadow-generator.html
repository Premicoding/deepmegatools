Under the Hood

Understanding the CSS Box Shadow Property

The box-shadow property adds shadow effects to HTML elements. Knowing its syntax helps you customise the generated code.

box-shadow: offset-x offset-y blur-radius spread-radius color;
Offset X
Controls the horizontal position of the shadow. Positive values move it right, negative values move it left.
Offset Y
Controls the vertical position of the shadow. Positive values move it down, negative values move it up.
Blur Radius
Controls how soft or blurred the shadow appears. Larger values generally produce softer shadows.
Spread Radius
Controls how much the shadow expands or contracts. Positive values expand it, negative values shrink it.
Color
Defines the shadow colour. Use named colours, hexadecimal values, RGB or RGBA colours.
Inset
An optional keyword that creates an inner shadow instead of a conventional outer shadow.

Not every value needs to be included in every shadow declaration. The exact effect depends on the values and the order in which the shadow layers are defined.

Basic Shadow

Create a simple shadow around a card or container.

box-shadow: 4px 4px 10px rgba(0, 0, 0, 0.2);

Soft Shadow

Use a subtle shadow to give elements a clean, modern appearance.

box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1);

Coloured Shadow

Add a colourful shadow to make a button or card stand out.

box-shadow: 0 0 20px rgba(0, 123, 255, 0.6);

Inset Shadow

Create an inner shadow for a pressed or recessed appearance.

box-shadow: inset 0 2px 8px rgba(0, 0, 0, 0.2);

Multiple Shadows

Combine multiple shadows to create a more detailed visual effect.

box-shadow: 0 5px 15px rgba(0,0,0,0.15),
             0 10px 30px rgba(0,0,0,0.08);

Pro Advice

Tips for Creating Better CSS Shadows

Follow these tips to make your shadows look professional.

  • Use subtle shadows for everyday interface elements such as cards and buttons.
  • Avoid excessive blur and spread when a clean, minimal design is your goal.
  • Select shadow colours that complement your website's colour palette.
  • Test your shadows against different backgrounds to make sure they stay visible.
  • Use multiple shadow layers carefully to avoid unnecessarily complicated designs.
  • Maintain consistency by using similar shadow styles for elements that serve similar purposes.
  • Consider performance and readability when adding elaborate effects to many elements.
