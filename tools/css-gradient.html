? What Is a CSS Gradient?

A CSS gradient is a CSS feature that creates a smooth transition between two or more colors — no image file required.

Gradients are commonly used in website backgrounds, navigation bars, buttons, hero sections, cards, text effects, and other design elements. CSS provides three main gradient types: linear, radial, and conic. You can also create repeating gradients and combine multiple gradients to produce more advanced background patterns.

Why it matters: gradients are rendered by the browser, so they scale perfectly on any screen, need no HTTP requests, and can be changed with a single line of code.

1 CSS Linear Gradient

A linear gradient creates a smooth transition between colors along a straight line. You can control the direction of the transition using keywords or an angle.

Syntax

background: linear-gradient(direction, color1, color2);

Example 1 — Simple Linear Gradient

.gradient-box {
  background: linear-gradient(to right, red, blue);
  height: 200px;
  border-radius: 12px;
}
Red → Blue

Example 2 — Three-Color Gradient

.gradient-box {
  background: linear-gradient(
    to right,
    #ff0080,
    #7928ca,
    #00c6ff
  );
  height: 200px;
}
Pink → Purple → Cyan

Example 3 — Diagonal Gradient

.gradient-box {
  background: linear-gradient(135deg, #667eea, #764ba2);
  height: 200px;
}
135° Diagonal
Linear gradients are useful for website headers, call-to-action buttons, hero sections, and modern UI components.

2 CSS Radial Gradient

A radial gradient creates a transition between colors that spreads outward from a central point. By default it uses an elliptical shape, but you can specify a circular shape.

Syntax

background: radial-gradient(shape, color1, color2);

Example 1 — Basic Radial Gradient

.gradient-box {
  background: radial-gradient(circle, yellow, red);
  height: 200px;
}
Yellow Center → Red Edge

Example 2 — Multiple Colors

.gradient-box {
  background: radial-gradient(
    circle,
    #ffffff,
    #667eea,
    #764ba2,
    #1a1a2e
  );
  height: 200px;
}
Multi-Color Glow

Example 3 — Custom Radial Position

.gradient-box {
  background: radial-gradient(
    circle at top left,
    #00c6ff,
    #0072ff,
    #001f54
  );
  height: 200px;
}
Top-Left Spotlight
Radial gradients are useful for glowing effects, decorative backgrounds, spotlight effects, and colorful website sections.

3 CSS Conic Gradient

A conic gradient creates a color transition around a central point, similar to the arrangement of colors on a color wheel.

Syntax

background: conic-gradient(color1, color2, color3);

Example 1 — Basic Conic Gradient

.gradient-box {
  background: conic-gradient(red, yellow, green, blue, red);
  height: 200px;
  border-radius: 50%;
}

Example 2 — Conic Gradient with an Angle

.gradient-box {
  background: conic-gradient(
    from 90deg,
    #ff0080,
    #7928ca,
    #00c6ff,
    #ff0080
  );
  height: 200px;
  border-radius: 50%;
}

Example 3 — Color Segments

.gradient-box {
  background: conic-gradient(
    red    0deg 90deg,
    yellow 90deg 180deg,
    blue   180deg 270deg,
    green  270deg 360deg
  );
  height: 200px;
  border-radius: 50%;
}
Conic gradients are useful for decorative circles, color wheels, pie-chart-style visuals, and creative UI designs.

4 CSS Repeating Gradients

Repeating gradients repeat a gradient pattern across an element. They can be used to create stripes, rings, and other decorative patterns.

Example 1 — Repeating Linear Gradient

.gradient-box {
  background: repeating-linear-gradient(
    45deg,
    #ff0080 0px,
    #ff0080 10px,
    #7928ca 10px,
    #7928ca 20px
  );
  height: 200px;
}
Diagonal Stripes

Example 2 — Repeating Radial Gradient

.gradient-box {
  background: repeating-radial-gradient(
    circle,
    #00c6ff 0px,
    #00c6ff 10px,
    #001f54 10px,
    #001f54 20px
  );
  height: 200px;
}
Rings

Example 3 — Repeating Conic Gradient

.gradient-box {
  background: repeating-conic-gradient(
    #667eea 0deg 15deg,
    #764ba2 15deg 30deg
  );
  height: 200px;
  border-radius: 50%;
}

5 How to Use Multiple CSS Gradients

You can combine multiple gradients in a single background declaration. Each gradient layer is separated by a comma.

Example — Multiple Gradient Background

.gradient-box {
  background:
    linear-gradient(135deg, rgba(255,0,128,.7), transparent),
    linear-gradient(45deg, #667eea, #764ba2);
  height: 250px;
  border-radius: 16px;
}
Two Layers Combined

6 Understanding Color Stops

Color stops define the colors used in a gradient and where those colors appear along the gradient line.

Example — Custom Color Stops

.gradient-box {
  background: linear-gradient(
    to right,
    red    0%,
    orange 25%,
    yellow 50%,
    green  75%,
    blue   100%
  );
  height: 200px;
}
0% → 100%

Using the same position for adjacent color stops creates a sharp color boundary instead of a smooth transition.

/* Sharp boundary at 50% */
background: linear-gradient(to right, #667eea 50%, #ff0080 50%);
Hard Edge

12 Best Practices

  • Choose suitable colors: match your website's theme and purpose.
  • Maintain readability: ensure text and interactive elements stay easy to see.
  • Use gradients consistently: avoid too many unrelated gradient styles on one page.
  • Optimize performance: gradients need no downloads, but complex designs and animations can still affect rendering.
  • Test on different screens: check mobile, tablet, and desktop displays.
  • Consider accessibility: verify text contrast, provide visible focus indicators, and respect reduced-motion preferences.
  • Use responsive layouts: make sure backgrounds work with changing element sizes.
  • Test browser support: confirm the CSS features you use are supported by your target browsers.

13 Common CSS Gradient Mistakes

  • Using too many colors without a clear design purpose.
  • Choosing colors that make text difficult to read.
  • Forgetting to specify an element's height or content when testing a background.
  • Using incorrect gradient syntax.
  • Adding unnecessary gradient layers that make the design hard to maintain.
  • Using animated gradients without considering users who prefer reduced motion.
  • Assuming that a gradient automatically provides sufficient text contrast.

14 Frequently Asked Questions

What is a CSS Gradient Generator?

A CSS Gradient Generator is a tool that helps you create custom gradient backgrounds and generate the CSS code needed to use them on a website.

What are the main types of CSS gradients?

The three main types are linear gradients, radial gradients, and conic gradients. CSS also supports repeating versions of these gradient types.

How do I create a linear gradient in CSS?

Use the linear-gradient() function with a direction and two or more colors.

background: linear-gradient(to right, red, blue);
Can I use more than two colors in a CSS gradient?

Yes. You can use multiple colors and control their positions with color stops.

background: linear-gradient(90deg, red, orange, yellow, green, blue);
Are CSS gradients better than background images?

CSS gradients can be a good alternative when you need a simple color transition or pattern. Complex illustrations or photographic backgrounds may still require images.

Can CSS gradients be animated?

Yes. You can animate suitable CSS properties or use techniques involving background positioning and pseudo-elements. Always test for performance and accessibility.

Do CSS gradients work on mobile devices?

CSS gradients are supported by modern mobile browsers. Test your designs on the devices and browsers relevant to your audience.
